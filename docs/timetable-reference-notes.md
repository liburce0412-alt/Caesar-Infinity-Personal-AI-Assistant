# 课程表优化（2026-09-22）

参考项目：

- [LazyTimetable](https://github.com/MoyuruAizawa/LazyTimetable)，Apache-2.0：Compose 时间轴、按时长定位、横纵向滚动。
- [Dawn Course / 破晓课程表](https://github.com/HF-CYGG/Dawn-Course)，GPL-3.0：独立课程表、课程详情、课程信息维护的产品交互。

本次仅参考布局和交互思路，代码在现有 Compose / Spectra 组件上独立实现，没有复制上述项目源码、素材或引入依赖。

## 范围

- 时间页的“今日课程”替换为周课表和按星期列表，保留截图、ICS 和手动导入入口。
- 时间轴按分钟定位；横向滚动查看七天，左侧时间轴固定。重叠课程及视觉触摸区域相交的短课程分列显示。
- 课程详情展示完整课程名、时间、地点、教师、周次；时间相交仅提示核对周次，不将不同教学周断言为实际冲突。
- 导入预览支持教师、周次；校验当前可见的时间文本，禁止保存无效时间、倒置区间或空课程名。移除课程后其他条目的输入保持稳定。

数据模型只有星期、时刻和自由文本周次，没有学期起始日期。本次展示所有教学周的安排，不计算当前教学周，不新增自动提醒或教务登录。原有 ICS 解析器对 RRULE 的日期范围、隔周规则和 EXDATE 支持仍不完整，本次没有扩展该解析器。

## 本地验证

使用 `TimetableLayoutTest` 检查重叠与短课程分列；`CourseTimetableUiTest` 检查详情、周末、空日、无效时间、大字体与深浅色截图。截图来自 Robolectric，不代表真实设备的共享背景渲染或用户视觉验收。

最终 6 项测试、`lintDebug`、`assembleDebug` 通过。测试覆盖 393dp 常规界面、320dp / 200% 字体；时间栏随字号放宽，避免时刻换行。候选 APK 位于 `artifacts/campusai-timetable-debug.apk`，尚未安装到设备。
