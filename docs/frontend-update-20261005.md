## 实现

- 心愿墙和树洞在登录启动、应用回到前台及进入页面时刷新；5 秒内的重复进入合并请求，手动刷新不受限。旧列表在刷新失败时仍保留。

## 对照之前的三屏参考图，仍值得优化的部分

以下为审阅发现，不代表本轮已经全部修改：

1. **个人页首屏密度**：现有大背景头像区和年度热力图占用较多高度，成就需要滚动后才能看到；参考图的身份、统计、徽章排列更紧凑。可降低头图高度，年度统计收起为摘要，让常用内容更靠前。
2. **Fluid 背景形状**：参考图有连续弯曲的玻璃褶皱和局部折射，目前实机更接近几条较直的发光带。下一轮应先调整曲面轮廓和光线方向，再微调色彩；单纯加亮、增加粒子或提高模糊不会得到相同观感。
3. **成就材质**：这次已解决相同 C 图标，加入不同外形；参考图仍有更明显的浮雕厚度和细窄镜面边缘。当前采用轻量原生矢量绘制，没有给每个徽章新增渲染器，后续可在同一 Canvas 增加克制的边缘层次。
4. **弹层透明度与层级**：实机“全部成就”底板叠加卡片后仍有较强的白雾感。可减少这一处重复底色，让主体与背景保持清晰层级，不要用降低文字对比度来换取通透。
5. **首页空状态占比**：没有今日记录时，达成区和健康空状态占据较大面积。可压缩为空状态摘要，把第一个有效操作和最近记录提到首屏。

参考图片为生成设计稿，只用于比较构图与材质方向；真机结果、Compose 测试渲染和生成图片不混为同一种验收证据。上述视觉调整应在轻量实现后比较滚动与触摸表现，不能只看静态截图。
