## 应用内行为

| 位置 | 行为 |
| --- | --- |
| AI 新对话 | 正常窗口显示约 175dp 的可见球体，位于“现在，想做什么？”上方；小窗口、键盘出现时按可用空间缩小。 |
| 语音输入 | 用户点击并满足原有权限、识别同意条件后，在输入框上方显示气泡。只使用 `SpeechRecognizer.onRmsChanged` 提供的音量估计；回调停止后衰减，取消、错误和离开页面时清零。 |
| 生成、朗读 | 同一个实例移动并缩小到顶部状态行；显示实际工具/处理阶段、流式回复、完成、取消或失败。朗读由 TTS 回调驱动，并提供停止操作；呼吸表示朗读状态，未采集或宣称实时朗读频谱。 |
| 首页 AI 入口 | 48dp 布局区域内显示约 41dp 的小气泡，横排开屏艺术字与精简的真实记录摘要，点击进入 AI 页。 |

转写仍只填入可编辑输入框，用户自行发送。使用系统语音 Activity 的兼容路径时，录音和界面由系统拥有，Caesar 不额外打开麦克风采集音量。转写超过 12 秒未返回会恢复为可重试状态。切换历史、开始生成、离开应用或页面时取消相应语音会话。

首页合并目标/达成信息，健康空态收为状态行，去掉重复激励和说明文字；健康详情、授权与同步、公告原文保留。独立品牌标题复用开屏 `caesarSignaturePath()`，保留原生文字无障碍语义；正文、历史对话和系统通知文字不转换为图片。

流体背景已改为亮芯、近晕和更宽淡的外晕，并按追加反馈恢复平行暖光带；去掉实体深谷阴影，运动速度保持不变，见 [材质参数](spectra-light-ribbon-plan.md)。生成的视觉基准图仅为概念参考。

## 渲染和降级

`CaesarGlassOrb` 仅注册一个区域，不创建独立 GL View 或循环。共享 `SpectraRenderer` 在现有半分辨率场景纹理之后，仅对气泡矩形执行局部 GLES2 着色，实际折射场景而非截图或文字。原有三个光学玻璃区域预算保留，气泡独立限为一颗。所有文字、按钮、语义和输入仍由 Compose 绘制。

材质第二轮以用户再次指定的三尺寸截图为外观基准，参考 demo 用于光学实现：手机主气泡约为 1.18 的宽高比，小状态球保持较圆。去掉覆盖整个下半球的灰白底色，让背景线条经过厚透镜产生可见弯折；亮度集中在底部焦散和细壳反光。中央波面适配 `glsl-playground` 的四谱线及带状光累积，交汇自然变白，保留局部柔光体积。聆听振幅继续来自真实 RMS，静待与处理只作状态呼吸，不沿用 demo 的模拟音频频段。每个气泡片元仍仅三次场景纹理采样，没有增加 renderer、FBO 或帧循环。

位置、尺寸和音量平滑在共享 GL 循环中处理，音量回调不写入页面 Compose 状态。减少动态效果、LOW 质量、shader/FBO 失败时显示缓存的原生静态材质；页面离开时注销区域。原有背景/折射质量不作削减。
