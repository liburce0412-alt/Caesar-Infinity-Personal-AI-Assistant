# 课表与外观使用说明

更新：2026-10-05。

## 导入与保存

在「时间 → 课程表 → 添加 / 导入」选择截图，可一次选择多张不同周的图片。应用读取截图里的“第几周”、星期、课程块节次和可见上课时间，逐张保存后直接显示；相同课程会跳过重复。取消导入会保留已经成功的图片结果。

课程先存本机，断网仍可查看。登录后后台同步到账号云端；本次生产库已支持节次字段。原图被省略号遮住的完整课程名无法恢复，文字识别可能有误，请点课程查看详情；截图没有下课时间时不会自动猜一个。

## 修改课程内容

点按一门课程，在详情选择「编辑课程」。可以补填或修改课程名称、校区/教学楼/教室位置、任课教师、星期、周次、起止节次和上课时间。截图中被省略号遮住的名称也可在这里补全。

按节次上课且不知道实际时间时，把起止时间都留空即可；按时间上课则把两个节次都留空，并填写有效的起止时间。各节上课时间可用逗号分隔，未确定的节次可留空。保存失败会保留当前输入，成功后立即更新本机课表，登录时再同步原课程，不会新建重复课程。

## 折叠课程表

到「我的 → 组件与内容 → 折叠课程表」。折叠只是收起显示，不会删除课程或停用同步；在时间页点击“展开”即可恢复。

## 配色与触摸效果

「我的 → 外观与体验」可选择五种背景色、深浅主题及经典 / Strba Fluid。首页今日行动、达成百分比、进度条和开始记录入口跟随当前背景色系。

浅色玻璃的淡彩追光位于手指附近的边框及紧邻边缘，移动时跟随、松手渐退；周围仅有淡淡的局部颜色过渡，面板保持透明，不常驻整圈彩虹。深色保持白色触摸高光，极光和流星仍可独立控制。关闭「跟手边框光」会同时关闭边框追光和跟手高光，仍保留玻璃静态轮廓；关闭总动效会停止动画。

## 反馈问题

请说明手机型号、主题、背景色、界面风格和具体操作。识别问题可提供原始课表截图，最好保留周次、星期和完整节次轴；公开反馈前遮住姓名、学号等个人信息。无需提交账号密码、私钥或健康原始记录。
