# 背景光带材质优化方案

用户确认：保留当前运动速度，主要问题是像实体丝带，而不是发光的光带。2026-10-13 已在本地候选中实现；随后按用户反馈增加更宽淡的外晕，并恢复平行暖光带。

## 保留

- 保留 `SpectraRenderer` 中现有 a/b/c 轨迹、位移速度、相位和触摸偏移。
- 继续使用同一个 renderer 和半分辨率场景纹理，让气泡、Dock 和玻璃按钮折射同一背景。
- 原生文字、控件、主题和动态效果开关保持各自的现有职责。

## 材质调整

1. **细亮光芯**：归一化半宽 0.0065，沿路径有轻微强弱变化。
2. **近处柔晕**：半宽 0.027、0.073，连续高斯衰减。
3. **更宽淡的外晕**：半宽 0.155，贡献系数仅 0.035，避免抢走正文对比度。
4. **平行暖光带**：与主芯偏移 0.022，半宽 0.009，另有 0.033 柔晕；暖色保持透明发光，不恢复深谷阴影。
5. **发光呼吸**：亮度 ±10%、光晕宽度 ±8%，各条错相。原有 a/b/c 位移与 current=t*0.24 保持不变。

采用 screen 混合保留光晕层次；浅色防止大片过曝，深色防止光晕覆盖文字；不把 AI 状态变成全屏闪烁。

## 实现和验收

已替换 `fluidFold` 的实体阴影表达式，不新增 bloom pass、纹理、全屏噪声或独立渲染循环。关闭动态效果时缓存对应路径、宽淡光晕与平行暖带，不启动帧循环。经典主题保留原有背景。

先比较浅深主题的固定时间截图和完整运动周期，再在同一设备亮度、质量和相近温度下对首页滚动、AI 空页、键盘场景采样。使用 Perfetto FrameTimeline 和 SurfaceFlinger 实际呈现间隔、p95/p99 与掉帧数据；120 Hz 请求和 GL 回调次数不作为达到 120 fps 的证据。
