# Caesar∞ v2.1.0

本次正式版更新液态玻璃交互、统一主要页面外观，并恢复可选的按周课程表。

## 外观与交互

- 浅色跟手彩光收窄为边框及紧邻边缘的淡彩光，移动时跟随手指，松手渐退；移除面板内部的大块彩色光晕。深色保留白色高光。
- 修复「外观与体验 → 跟手边框光」关闭后仍绘制跟手高光的问题，开关同时控制 Compose 与 GL 光效；玻璃自身的静态轮廓仍保留。
- 统一五个主页面的透明材质、留白和控件，减少大卡片堆叠；首页达成区域跟随背景配色。
- 优化 Fluid 背景变化、暗色极光与流星，保留各项独立开关。
- 共享玻璃渲染缓存、限制渲染区域，并按需绘制年度热力图。实测常规帧耗时降低，极端切页耗时仍有波动。

## 可选课程表

- 在「我的 → 组件与内容」折叠或展开，不删除课程。
- 可一次导入多张不同周的截图，自动读取周次、星期、节次及可见上课时间，直接本地保存并去重；登录后后台同步。
- 用户提供的第 4、5 周截图已在手机实际批量导入，分别识别 11、10 项课程；重复导入不会增加课程。
- 被省略号遮挡的完整课程名无法恢复，识别文字仍可能有误；缺失的下课时间不会被凭空补全。

## 下载与升级

下载本页 `caesar-v2.1.0.apk`。附带 `SHA256SUMS.txt` 校验文件。

沿用既有 GitHub 正式发布签名，版本号 2.1.0、版本代码 4，可覆盖升级兼容签名的旧版本。请保留应用数据；不要为升级卸载原应用。自托管后端需应用仓库中的课程节次迁移；当前正式服务已完成兼容迁移并保留旧课程。

新版页面截图和使用说明见仓库 README 与 `docs/timetable-and-appearance.md`。当前版本的边缘彩光已在真机查看开关前后效果；按用户要求结束追加验收，发布流程仍执行既有构建检查。
